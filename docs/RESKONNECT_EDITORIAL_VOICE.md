# ResKonnect Editorial Style

## Our writing standard

Use confident, human language. Write like a thoughtful person speaking to a student, a parent, a landlord or a partner.

Avoid decorative dashes as sentence separators in headings, promotional materials, buttons, cards, descriptions, explanations, notification messages and generated content.

Prefer a short sentence, a natural comma or a colon where it genuinely improves readability. Use complete sentences that sound warm and purposeful. Avoid mechanical slogans and long chains of clauses.

Prefer plain descriptive phrases such as "student accommodation", "single room requests", "supported by AI", "live updates" and "easy to use".

Never modify the spelling of people, residences, towns, institution names, legal text, serial numbers or identifiers merely to satisfy a style rule. Technical hyphens in URLs, code, database keys, negative numbers, date formats, file paths and phone numbers must remain intact.

## Implementation

The shared editorial display helper formats presentation text, accessible labels, titles, image descriptions and placeholders. It does not modify user input values, content editors, code blocks, live maps or stored records.

The SEO component applies the same style to page titles and descriptions. The public landing and About copy use polished text directly in source.

When preparing new banners or promotional images, write the approved display copy in this style before generating or uploading artwork. A site display formatter cannot change lettering baked into an image.

Run the editorial copy regression tests and release checks before publishing.
