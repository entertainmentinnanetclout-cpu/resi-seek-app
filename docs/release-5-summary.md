# Release 5 — Student Housing Intelligence Network

Release 5 turns the existing accommodation marketplace and ResMap activity into an aggregate student-living intelligence layer.

- Phase 20 — live accommodation supply map.
- Phase 21 — demand heat maps.
- Phase 22 — property partner analytics.
- Phase 23 — institution accommodation intelligence.
- Phase 24 — investment/development opportunity intelligence.

The release also includes the final iPhone Safari ResMap rendering hardening required before production promotion. See `release-5-gate-record.md` and `resmap-mobile-regression.md`.
