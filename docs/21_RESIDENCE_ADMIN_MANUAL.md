# 21. Residence Admin Manual (Portal)

## 1. Handling Applications
- **Dashboard**: Quick view of applications needing attention.
- **Inbox**: Your main workspace. Click "Review" to see student documents.
- **Approving**: Only approve once ID and Proof of Registration are verified.

## 2. Document Review
- **ID**: Must be clear and valid.
- **Proof of Reg**: Must be for the current academic year.
- **Rejection**: If a document is blurry, select "Rejected" and provide a reason. The student will be notified to re-upload.

## 3. Handover Packs
- At the end of the intake cycle, use the **Analytics/Exports** tab to download the full ZIP of student data for institutional submission.
