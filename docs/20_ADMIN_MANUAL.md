# 20. Admin Manual (God Mode)

## 1. Navigating the Hubs
- **Operations**: Use the "Applications" tab to filter by status. Click a student name to see their full profile and document history.
- **Media**: When adding news, ensure images are in 16:9 ratio for best display.
- **System**: Monitor the "Backend Health" card. If it turns red, contact the System Operator immediately.

## 2. Managing Residence Portals
1. Go to **Operations Hub -> Portals**.
2. Click "Create Portal Account".
3. Select the Residence from the dropdown.
4. Enter the partner's email.
5. The system will provision a specialist account and notify the partner.

## 3. Moderation Workflow
- **Marketplace**: Review unverified listings. Ensure no prohibited items or incorrect pricing.
- **Landlord Apps**: Review new property requests. Verify the address and campus proximity before clicking "Accredit".
